# 图片与使用说明

[返回首页](../README.md)

本页选取8张已核对作者与开放许可的图片，外链展示原图，不把图片下载后重新授权。其他92个条目提供博物馆配图／资料入口，并不声称已为每条选定可转载图片。图片无法加载时可点原文件页；第三方热链可用性会变化。

注意：骨架装架可能含复模和补配，不等于一具完整原骨；艺术复原不是照片，其色彩和软组织通常包含推测。腕龙图片选用Brachiosaurus altithorax，避免把柏林的Giraffatitan装架误标为北美腕龙。
