# 按类群学习

[返回首页](../README.md)

以下是便于初学者阅读的分组，并非完整系统发育树。“大型／小型”不等于正式分类阶元；鸟类是恐龙的一支。

- [早期恐龙与蜥脚形类 · 5条](groups/early-dinosaurs.md)：从早期小型恐龙与长颈植食谱系入门。这里是学习分组，不表示全部成员组成一个单系群。
- [大型兽脚类 · 24条](groups/large-theropods.md)：肉食大型恐龙的学习分组；镰刀龙属于兽脚类但以植食为主，不能用体型替代食性判断。
- [小型兽脚类与早期鸟类 · 13条](groups/small-theropods.md)：比较有羽毛恐龙、驰龙与早期鸟类。始祖鸟属于鸟翼类；鸟类包含在恐龙之内。
- [蜥脚类 · 14条](groups/sauropods.md)：长颈、四足植食的主干分组；不同属的颈部比例、体长和体重不能直接套用。
- [角龙类 · 9条](groups/ceratopsians.md)：比较喙、颈盾、鼻角与眉角；并非每一种角龙都有三只长角。
- [鸟脚类及近缘小型鸟臀类 · 16条](groups/ornithopods.md)：从小型鸟臀类到大型鸭嘴龙的学习分组，兼顾双足与四足姿态。
- [剑龙类与早期装甲类 · 6条](groups/stegosaurs.md)：观察背板、尾刺与早期皮内成骨；小盾龙作为早期装甲谱系对照。
- [甲龙类 · 11条](groups/ankylosaurs.md)：比较有尾槌的甲龙科与缺少尾槌的其他装甲恐龙，避免一概而论。
- [肿头龙类 · 2条](groups/pachycephalosaurs.md)：比较头顶穹隆和颅骨装饰；撞头行为是有证据支持但仍需区分情境的解释。
