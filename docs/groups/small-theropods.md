# 小型兽脚类与早期鸟类 · 13条

[类群总览](../TAXONOMY.md) · [图鉴](../DINOSAURS.md)

比较有羽毛恐龙、驰龙与早期鸟类。始祖鸟属于鸟翼类；鸟类包含在恐龙之内。

## DINO-058 始祖鸟 · Archaeopteryx

- 年代：晚侏罗世；类群：小型兽脚类与早期鸟类；食性：肉食。
- 规格：参考体长约 **0.5米**；体重不填（缺少所选口径）。NHM科普目录参考估值；不是最新最大值或全属通用范围。
- 化石发现地：德国（现代地理名称）。

兼具牙齿、长骨尾和羽毛等组合特征，是研究鸟类起源的重要化石。

来源：[NHM博物馆目录](https://www.nhm.ac.uk/discover/dino-directory/archaeopteryx.html)；[配图与资料原页](https://www.nhm.ac.uk/discover/dino-directory/archaeopteryx.html)。核对：2026-10-18。

## DINO-097 迅猛龙（伶盗龙） · Velociraptor

- 年代：晚白垩世；类群：小型兽脚类与早期鸟类；食性：肉食。
- 规格：参考体长约 **1.8米**；参考体重约0.007吨。NHM科普目录参考估值；不是最新最大值或全属通用范围。
- 化石发现地：蒙古国（现代地理名称）。

迅猛龙（伶盗龙）的属名释义为'quick plunderer'。本条用晚白垩世、小型兽脚类与蒙古国的化石记录定位；不同属的相似中文译名或相近体型不构成同物种证据。

- 小型驰龙，后足第二趾具有显著镰刀状爪，尾部帮助身体保持平衡。
- 电影中的“迅猛龙”明显放大了体型，外形还参考了恐爪龙；应分开记录影视形象与古生物事实。
- 羽毛覆盖有科学依据；羽毛存在不等于具有现代鸟类那样的飞行能力。
- 常见中文名迅猛龙、伶盗龙对应本条 Velociraptor；不与 Deinonychus（恐爪龙）合并。

来源：[NHM博物馆目录](https://www.nhm.ac.uk/discover/dino-directory/velociraptor.html)；[配图与资料原页](https://commons.wikimedia.org/wiki/File:Velociraptor_fruita_1_(white_background).png)。核对：2026-10-18。
